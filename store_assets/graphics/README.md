# Graphics Assets for Store Listing

## Overview
This directory contains promotional graphics for The Notification Thriller's store presence.

## Required Graphics

### 1. Feature Graphic (REQUIRED)
- **Filename**: `feature_graphic.png`
- **Dimensions**: 1024 x 500 pixels (exact)
- **Format**: PNG or JPEG
- **File Size**: Max 1 MB
- **Usage**: Top of Play Store listing, promotional carousels

#### Design Guidelines
```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  [ICON]     THE NOTIFICATION THRILLER                    │
│             A Real-Time Mystery That Finds You           │
│                                                          │
│    [Notification Bell]  [Character Silhouette]           │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**Elements to Include:**
- App icon or game logo
- Game title text (large, readable)
- Tagline or key feature
- Thematic imagery (notification bell, mysterious elements)
- Dark, thriller-appropriate color scheme

**Safe Zone:**
- Keep critical elements in center 922 x 450 pixels
- Allow 51px margin on sides
- Allow 25px margin top and bottom

**Colors:**
- Background: Dark gradient (#1a1a2e to #16213e)
- Primary: Blue (#2196F3)
- Accent: Cyan (#03DAC5)
- Alert: Red (#e53935) for thriller elements

### 2. App Icon High-Res (REQUIRED)
- **Filename**: `app_icon_512.png`
- **Dimensions**: 512 x 512 pixels
- **Format**: PNG (32-bit with alpha)
- **File Size**: Max 1 MB
- **Usage**: Play Store listing, search results

**Design:**
- Same as launcher icon but high resolution
- See `app/icons/` directory for templates
- Ensure clarity at various sizes

## Creating Feature Graphic

### Design Tools

#### Professional
- **Adobe Photoshop**: Industry standard
- **Adobe Illustrator**: Vector design
- **Figma**: Web-based design tool
- **Sketch**: macOS design app

#### Free Alternatives
- **GIMP**: Free Photoshop alternative
- **Inkscape**: Free vector editor
- **Canva**: Easy online design tool
- **Photopea**: Browser-based editor

### Template Structure

1. **Background Layer**
   - Dark gradient or solid color
   - Matches app theme

2. **Imagery Layer**
   - App icon (left side)
   - Thematic elements (notification bell, mysterious symbols)
   - Character silhouettes (optional)

3. **Text Layer**
   - Game title (prominent)
   - Tagline (smaller, supporting)
   - High contrast for readability

4. **Effects Layer**
   - Glow effects
   - Shadows for depth
   - Subtle animations indicators

### Typography

**Title Font:**
- Bold, modern sans-serif
- 60-80pt size
- High contrast against background
- Readable at thumbnail size

**Tagline Font:**
- Medium weight sans-serif
- 30-40pt size
- Complementary to title
- Clear and concise

**Recommended Fonts:**
- Roboto Bold (Android standard)
- Montserrat Bold
- Poppins SemiBold
- Open Sans Bold

### Color Palette

```
Primary Dark:   #1a1a2e  (Background dark)
Secondary Dark: #16213e  (Background light)
Primary Blue:   #2196F3  (Main accent)
Deep Blue:      #0f3460  (Secondary accent)
Cyan:          #03DAC5  (Highlights)
Alert Red:     #e53935  (Thriller elements)
White:         #FFFFFF  (Text)
```

## Quality Checklist

### Before Uploading

- [ ] Dimensions are exact (1024x500 for feature graphic)
- [ ] File format is correct (PNG or JPEG)
- [ ] File size is under 1 MB
- [ ] Text is readable at thumbnail size
- [ ] Colors match app branding
- [ ] No copyright violations
- [ ] High resolution and sharp
- [ ] No pixelation or artifacts
- [ ] Tested on different backgrounds
- [ ] Looks good in dark and light themes

### Content Rules

✅ **Allowed:**
- App logo and branding
- Game screenshots
- Original artwork
- Licensed assets
- Text descriptions
- Thematic elements

❌ **Not Allowed:**
- Copyrighted images (without permission)
- Misleading content
- Competitor logos
- Inappropriate content
- Low-quality images
- Unrelated imagery

## Optimization Tips

### File Size Reduction
- Use appropriate compression
- Remove unnecessary metadata
- Optimize PNG with tools like TinyPNG
- Use JPEG for photos, PNG for graphics
- Keep quality high but file size reasonable

### Visual Impact
- Strong contrast for visibility
- Clear hierarchy (title > tagline > details)
- Minimal text (let images speak)
- Focus on unique selling points
- Create emotional connection

### A/B Testing
Consider creating multiple versions:
- Different layouts
- Various color schemes
- Alternative taglines
- Diverse imagery

Test which performs better in terms of:
- Click-through rate
- Conversion rate
- User engagement
