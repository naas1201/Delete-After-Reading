# 10-inch Tablet Screenshots

## Specifications
- **Format**: PNG or JPEG
- **Recommended Size**: 2560x1600 (landscape) or 1600x2560 (portrait)
- **Minimum**: 2 screenshots (if providing tablet screenshots)
- **Maximum**: 8 screenshots

## Why Include 10" Tablet Screenshots?

### Benefits
- Premium tablet experience showcase
- Appeals to high-end tablet users
- Demonstrates professional polish
- Better for media consumption apps
- Increases tablet market penetration

### Target Devices
- Google Pixel Tablet
- Samsung Galaxy Tab S8/S9
- Lenovo Tab P11/P12
- iPad competitors (Android)
- Premium Android tablets

## Unique Considerations

### Large Screen Optimization
- Even more screen real estate
- Multi-pane layouts shine here
- Desktop-like experience possible
- Productivity features highlighted

### Landscape-First Design
10" tablets are often used in landscape:
- Wider chat interface
- Sidebar navigation (optional)
- Split view capabilities
- Better for media consumption

## Screenshot Strategy

### Showcase Premium Experience

#### 1. Full Landscape View

## Creating 10" Tablet Screenshots

### Emulator Setup
```
Device: Pixel Tablet or Galaxy Tab S8
Resolution: 2560 x 1600
DPI: 320 (xhdpi)
Android: 11 or higher
Orientation: Landscape preferred
```

### Real Device Testing
If available, use actual 10" tablet:
- More accurate representation
- Better performance testing
- Real-world user experience
- Authentic screenshots

## Layout Optimization

### Maximize Screen Space
- Use wide layout designs
- Multi-column when appropriate
- Larger text for readability
- Generous spacing

### Don't Just Scale Up
- Redesign for large screens
- Add tablet-specific features
- Optimize touch targets
- Improve information density

## Quality Checklist

- [ ] Resolution is 2560x1600 or higher
- [ ] Landscape orientation (recommended)
- [ ] Shows tablet-optimized layout
- [ ] Clear and professional
- [ ] Demonstrates value on tablets
- [ ] No pixelation or blur
- [ ] Proper aspect ratio
- [ ] File size under limit

### Target Audience
- Professionals

- Power users

---

**Pro Tip**: 10" tablet screenshots are most valuable if your app has genuine tablet optimizations. If it's just a scaled-up phone app, you might skip this category or focus on showing how it still works well on tablets despite being optimized for phones.
