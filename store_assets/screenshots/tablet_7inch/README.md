# 7-inch Tablet Screenshots

## Specifications
- **Format**: PNG or JPEG
- **Recommended Size**: 1920x1200 (landscape) or 1200x1920 (portrait)
- **Minimum**: 2 screenshots (if providing tablet screenshots)
- **Maximum**: 8 screenshots

## Why Include Tablet Screenshots?

### Benefits
- Better discoverability on tablets
- Shows optimized layout for larger screens
- Increases conversion for tablet users
- Demonstrates professional tablet support
- Google Play highlights tablet-optimized apps

### Target Devices
- Nexus 7 (2013)
- Samsung Galaxy Tab A 7.0
- Amazon Fire 7
- Lenovo Tab M7
- Other 7" Android tablets

## Layout Considerations

### Landscape Orientation (Recommended)
- Makes use of wider screen space
- Side-by-side UI elements
- Better for two-column layouts
- More immersive chat experience

### Portrait Orientation
- Similar to phone but larger
- More messages visible at once
- Comfortable for reading
- Natural tablet holding position

## Creating Tablet Screenshots

### Method 1: Real Tablet
1. Install app on 7" tablet
2. Take screenshots as with phone
3. Transfer and process

### Method 2: Emulator
1. Create 7" tablet AVD in Android Studio
2. Resolution: 1280x800 or 1920x1200
3. Test app and screenshot
4. Process for store

### Emulator Configuration
```
Device: Nexus 7 (2013)
Resolution: 1920 x 1200
DPI: 323 (xhdpi)
Android: 10 or higher
```

## Differences from Phone Screenshots

### Larger Canvas
- Show more content on screen
- Utilize extra space effectively
- Don't just scale up phone UI

### Layout Adjustments
- Two-column layouts (if implemented)
- Wider chat bubbles
- More context visible
- Larger touch targets

### Quality Standards
Same as phone screenshots:
- High resolution
- Clear text
- Professional presentation
- Accurate representation
