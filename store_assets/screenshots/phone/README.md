# Phone Screenshots

## Required Specifications
- **Format**: PNG or JPEG (PNG recommended)
- **Minimum**: 2 screenshots
- **Maximum**: 8 screenshots
- **Aspect Ratio**: 16:9 or 9:16
- **Recommended Size**: 1080x1920 (portrait) or 1920x1080 (landscape)

## Screenshot Naming Convention

Use descriptive names for easy management:
```
01_splash_screen.png          # Welcome/splash screen
02_main_chat_interface.png    # Main chat UI
03_notification_example.png   # Notification in action
04_character_sarah.png        # Character introduction
05_thriller_moment.png        # Intense story moment

08_story_conclusion.png       # Satisfying moment
```

## Taking Screenshots

### Method 1: Real Device
1. Install app on Android device
2. Navigate to desired screen
3. Press **Power + Volume Down**
4. Transfer to computer
5. Crop/resize if needed

### Method 2: Android Emulator
1. Launch emulator in Android Studio
2. Open app to desired screen
3. Click camera icon in toolbar
4. Screenshot saved to desktop
5. Process as needed

### Method 3: Mockup with Device Frame
1. Take basic screenshot
2. Upload to mockup generator
3. Choose device frame (Pixel, Galaxy, etc.)
4. Download framed screenshot
5. Use in store listing

## Post-Processing Tips

### Enhancement
- Adjust brightness if too dark
- Increase contrast slightly
- Ensure text is readable
- Remove any personal info
- Add subtle shadow to device frame

### Optimization
- Resize to exact requirements
- Compress without quality loss
- Convert to PNG if JPEG
- Check file size (<8MB)
- Test visibility at thumbnail size

## Tools

### Screenshot Tools
- **ADB**: `adb shell screencap -p /sdcard/screenshot.png`
- **Android Studio**: Built-in emulator screenshot
- **Scrcpy**: Mirror and screenshot Android device

### Image Editors
- **GIMP**: Free, powerful editor
- **Photoshop**: Professional editing
- **Paint.NET**: Simple Windows editor
- **Pixlr**: Online editor

### Device Frame Tools
- **Device Art Generator**: https://developer.android.com/distribute/marketing-tools/device-art-generator
- **Mockuphone**: https://mockuphone.com/
- **Cleanmock**: https://cleanmock.com/

## Quality Standards

### Must Have
✅ High resolution (at least 1080p)
✅ Clear, readable text
✅ Proper lighting/contrast
✅ No personal information
✅ Represents actual app

### Should Avoid
❌ Blurry or pixelated images
❌ Misleading content
❌ Copyright violations
❌ Poor composition
❌ Incorrect aspect ratio

## Store Guidelines Compliance

- No sexually suggestive content
- No violence or gore
- No hate speech or discrimination
- No misleading claims
- No unrelated content
- Accurate representation of app
